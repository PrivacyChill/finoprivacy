# Fino

The website https://finoprivacy.com: a free, searchable collection of GDPR enforcement decisions from across Europe, checked against the regulators' originals.

This repository holds only the published website (`site/`), which GitHub Pages serves. A personal, non-commercial project. Not legal advice.

## Data licence

The decision list comes from [enforcementtracker.com, provided by CMS](https://www.enforcementtracker.com/) and [GDPRhub](https://gdprhub.eu/) (noyb), both licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
