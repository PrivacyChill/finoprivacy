Fino reads decisions from regulators in many countries and languages, and gets some details wrong: a date, an amount, the name of an organisation, the state of an appeal. Each entry says what the page said and what it says now, with a link to the page and, where the right fact is written elsewhere, a link to that source.

The list shows only the errors Fino found or was told about. A page that is not on it is not proven correct.

Found an error? Write to hello@finoprivacy.com and quote the decision number. If you can, say where the right fact is written.

When a correction concerns a private person, a sole trader or a small partnership, the detail is withheld: Fino does not name them. This page leaves out the detail of 11 entries; the data file holds the full list. Not legal advice.
