Fonts served from this site so that visitors' browsers never contact a font provider.
All four are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org):
- Fraunces, by Undercase Type (https://github.com/undercasetype/Fraunces)
- Atkinson Hyperlegible, by the Braille Institute (https://www.brailleinstitute.org/freefont/)
- IBM Plex Mono, by IBM (https://github.com/IBM/plex)
- Instrument Sans, by the Instrument Sans Project Authors (https://github.com/Instrument/instrument-sans):
  only the corporate look uses it, so the Fino look never downloads it
Only the Latin subset is included (Instrument Sans also has Latin Extended, for names like Łódź or Ștefan).
